Created in Phase 0 — 2026-11-01. Nothing in this file has been verified yet: **every item is OPEN**. No datasheets, Traccar documentation, provider documentation or legal sources were consulted during Phase 0 beyond what is stated in `docs/PROJECT_SPEC.md` and the project skills (which are themselves general knowledge, not verified for a pinned Traccar version).

When an item is resolved, change its status, add the **outcome**, **date** and **source**, and update the document that depended on the assumption. Do not delete resolved items.

Statuses: `OPEN` · `IN PROGRESS` · `RESOLVED` · `ACCEPTED RISK`.
"Needed by" = latest milestone at which the answer must be known; "Design assumption" = what the design does meanwhile (so the unknown is configurable or gated, per workflow §6).
